# Issue Completion Checklist

## Before Implementation

- [ ] 관련 `docs/00~09`를 읽었다.
- [ ] 관련 spec이 있다.
- [ ] acceptance criteria가 명확하다.
- [ ] verification level이 정해졌다.
- [ ] Open Questions가 해결되었거나 명시되어 있다.

## During Implementation

- [ ] 문서의 레이어 구조를 지켰다.
- [ ] 새 결정은 `decisions.md` 또는 ADR에 기록했다.
- [ ] 임시 코드 또는 TODO를 무단으로 남기지 않았다.
- [ ] 에러 처리를 숨기지 않았다.

## Before Claiming Done

- [ ] required verification level을 충족했다.
- [ ] 실행한 명령과 결과를 기록했다.
- [ ] API 변경 시 실제 HTTP request를 수행했다.
- [ ] 예상하지 못한 500이 없음을 확인했다.
- [ ] 서버 로그를 확인했다.
- [ ] 문서 업데이트 필요 여부를 확인했다.
- [ ] Done Claim을 작성했다.
